# Answers — writing principles

This folder holds the *content* that answers each part of the brief — concise, decisions rather than descriptions, sourced or explicitly labeled ASSUMED. Not the deck. The deck and its storytelling are designed later, by Renata, from what's written here.

Shared standard, straight from the brief itself: "We are evaluating how you think, not how you decorate slides. A recommendation beats a survey of options. Clarity beats polish." Every file here should read that way — a stated position, not a menu of options.
